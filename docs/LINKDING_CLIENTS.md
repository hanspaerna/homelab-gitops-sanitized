# Linkding desktop/mobile clients and their configuration

This note describes the most convenient and seamless approach of replacing browser-specific bookmarks with Linkding that I could achieve.
The idea is to make as few clicks as possible when searching for the bookmark or adding one, i.e. making it similar to the native browser bookmarks.

## Desktop (Firefox)

1. Install the official Linkding extension
2. In "Customize", put Bookmarks toolbar into the row with address bar to save the vertical space
3. Create the only bookmark in the toolbar pointing to Linkding's main page
4. Go to "about:config", set "browser.tabs.LoadBookmarksInTabs" to "true"
5. If starting with a clean installation of Linkding, set "Open bookmarks in" to "Same page" in the web UI
6. Enable Favicons in Linkding's instance settings, if not yet

## Android

1. Install Pinkt app and connect it to Linkding server. Use its interface to search for a bookmark
2. Use "Share" button in the browser and then tap Pinkt's "Save bookmark" option to save a bookmark
